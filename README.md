# Minecraft Bedrock Addon Development Tools

CLI tools for creating, building, and managing Minecraft Bedrock addons with Dropbox sync to iPad.

## Overview

This toolset provides a streamlined workflow for developing Minecraft Bedrock addons on Linux and syncing them to iPad via Dropbox.

## Tools

- **mcaddon** - Main CLI tool for addon management
- **validate-json.sh** - Validates JSON files in addon directories
- **package-addon.sh** - Packages addons into .mcaddon and .mcpack files

## Requirements

- Python 3.12+
- `zip`, `jq`, `inotify-tools` (installed via your package manager)
- Dropbox (optional, for iPad sync)

On Debian/Ubuntu:
```bash
sudo apt install zip jq inotify-tools python3 python3-pip
```

## Installation

### Using uv (recommended)

1. Install uv if you haven't already:
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

2. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/mcaddon-tools.git
   cd mcaddon-tools
   ```

3. Install using uv:
   ```bash
   uv pip install -e .
   ```

### Using pip

```bash
git clone https://github.com/yourusername/mcaddon-tools.git
cd mcaddon-tools
pip install -e .
```

After installation, the `mcaddon` command will be available in your PATH.

## Usage

### Create a New Addon

```bash
mcaddon init my_addon
```

This creates:
```
~/minecraft-addons/my_addon/
├── behavior_pack/
│   ├── manifest.json
│   ├── entities/
│   ├── items/
│   ├── blocks/
│   ├── recipes/
│   └── functions/
└── resource_pack/
    ├── manifest.json
    ├── textures/
    ├── models/
    ├── sounds/
    └── animations/
```

### Build Addon

Build and sync to Dropbox (for iPad):
```bash
mcaddon build my_addon
```

Build locally only:
```bash
mcaddon build my_addon --local
```

### Watch Mode (Auto-rebuild)

Automatically rebuild when files change:
```bash
mcaddon watch my_addon
```

Watch and build locally:
```bash
mcaddon watch my_addon --local
```

### List Addons

```bash
mcaddon list
```

Output:
```
Available Addons
  • my_addon           [BP, RP] ✓ built
  • test_addon         [BP]     not built
```

## Directory Structure

```
~/minecraft-addons/
├── tools/              # This toolset
├── builds/             # Local builds (--local flag)
├── my_addon/           # Your addon projects
├── another_addon/
└── ...

~/Dropbox/Minecraft/    # Synced builds (default)
└── *.mcaddon files
```

## Workflow

### Basic Development

1. Create addon: `mcaddon init cool_weapons`
2. Edit files in `~/minecraft-addons/cool_weapons/`
3. Build to Dropbox: `mcaddon build cool_weapons`
4. On iPad: Files → Dropbox → Minecraft → tap `cool_weapons.mcaddon`
5. Open in Minecraft

### Active Development with Auto-rebuild

1. Start watch mode: `mcaddon watch cool_weapons`
2. Edit files - changes automatically build and sync to Dropbox
3. Test on iPad by re-importing the addon

## File Formats

- `.mcpack` - Single pack (behavior OR resource pack)
- `.mcaddon` - Complete addon (both packs bundled together)

## Manifest Structure

Each pack requires a `manifest.json` with unique UUIDs (automatically generated by `init`):

```json
{
  "format_version": 2,
  "header": {
    "name": "My Addon Name",
    "description": "Addon Description",
    "uuid": "unique-uuid-here",
    "version": [1, 0, 0],
    "min_engine_version": [1, 20, 0]
  },
  "modules": [
    {
      "type": "data",
      "uuid": "another-unique-uuid",
      "version": [1, 0, 0]
    }
  ]
}
```

## Troubleshooting

### JSON Validation Errors

Manually validate:
```bash
validate-json.sh ~/minecraft-addons/my_addon
```

Or check specific file:
```bash
jq empty ~/minecraft-addons/my_addon/behavior_pack/manifest.json
```

### Dropbox Not Syncing

Check status:
```bash
dropbox status
```

Restart Dropbox:
```bash
dropbox stop
dropbox start
```

### Addon Not Appearing on iPad

1. Check manifest UUIDs are unique
2. Verify `format_version` is 2
3. Ensure Dropbox sync is complete
4. Force refresh Files app on iPad
5. Check Minecraft version matches `min_engine_version`

### Watch Mode Not Working

Ensure `inotify-tools` is installed:
```bash
sudo apt install inotify-tools
```

Test manually:
```bash
inotifywait -r -e modify ~/minecraft-addons/my_addon
```

- Keep addons in version control (git)
- Use `.gitignore` to exclude build artifacts:
  ```
  *.mcaddon
  *.mcpack
  .DS_Store
  ```
- Test locally before syncing to Dropbox
- Use descriptive names for entities, items, and files
